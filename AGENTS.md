
# For every new task that require code modification: 
## Phase 1

1. fetch latest remote changes
2. create a new branch for the task
3. show change summaries/reviews
4. wait for user approval

do not modify code without user approval

## Phase 2
1. Implement approved plan.
2. Run tests/lint/build checks.
3. Summarize changes.
4. Wait for user testing.

Do not commit yet.

## Phase 3
1. Create PR.
2. Provide PR summary.

Never skip approval gates.
